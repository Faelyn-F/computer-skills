☁️ Google Drive

گوگل درایو

🖐️ Try Interactive Practice — تمرین تعاملی را امتحان کنید
  1. 1

    Open Drive

    Drive را باز کنید

    🖼️

    Screenshot: Google Drive homepage

    تصویر: صفحه اصلی Google Drive

    🔨 Practice

    🔨 تمرین

    Open your web browser. Type drive.google.com in the address bar. Press Enter.

    مرورگر خود را باز کنید. در نوار آدرس drive.google.com را تایپ کنید. Enter را بزنید.

  2. 2

    Create a folder

    یک پوشه ایجاد کنید

    🖼️

    Screenshot: New folder button in Drive

    تصویر: دکمه پوشه جدید در Drive

    🔨 Practice

    🔨 تمرین

    Click the + New button (top left). Click Folder. Type a name for your folder. Click Create.

    روی دکمه + New (بالا سمت چپ) کلیک کنید. روی Folder کلیک کنید. یک نام برای پوشه خود تایپ کنید. روی Create کلیک کنید.

  3. 3

    Upload a file

    یک فایل آپلود کنید

    🖼️

    Screenshot: File upload option in the New menu

    تصویر: گزینه آپلود فایل در منوی New

    🔨 Practice

    🔨 تمرین

    Click the + New button. Click File upload. Choose a file from your computer. Click Open. The file uploads to Drive.

    روی دکمه + New کلیک کنید. روی File upload کلیک کنید. یک فایل از کامپیوتر خود انتخاب کنید. روی Open کلیک کنید. فایل در Drive آپلود می‌شود.

  4. 4

    Find a file

    یک فایل را پیدا کنید

    🖼️

    Screenshot: Search bar at the top of Drive

    تصویر: نوار جستجو در بالای Drive

    🔨 Practice

    🔨 تمرین

    Click the Search bar at the top. Type the name of your file. Press Enter. Drive shows matching files.

    روی نوار جستجو در بالا کلیک کنید. نام فایل خود را تایپ کنید. Enter را بزنید. Drive فایل‌های مطابق را نشان می‌دهد.

  5. 5

    Open a file

    یک فایل را باز کنید

    🖼️

    Screenshot: Double-click a file in Drive

    تصویر: دوبار کلیک روی یک فایل در Drive

    🔨 Practice

    🔨 تمرین

    Find your file. Double-click the file name (click twice quickly). The file opens.

    فایل خود را پیدا کنید. دوبار کلیک روی نام فایل (دو بار سریع کلیک کنید). فایل باز می‌شود.

  6. 6

    Share a file safely

    یک فایل را به صورت امن به اشتراک بگذارید

    🖼️

    Screenshot: Share button and sharing settings

    تصویر: دکمه اشتراک‌گذاری و تنظیمات آن

    🔨 Practice

    🔨 تمرین

    Right-click a file. Click Share. Enter the person's email. Set permission to Viewer (safe setting). Click Send.

    روی یک فایل راست‌کلیک کنید. روی Share کلیک کنید. ایمیل فرد را وارد کنید. دسترسی را روی Viewer (تنظیمات امن) بگذارید. روی Send کلیک کنید.
