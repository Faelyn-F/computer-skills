📄 Create a Document

ایجاد سند

  1. 1

    Open Google Docs

    Google Docs را باز کنید

    🖼️

    Screenshot: Google Docs homepage

    تصویر: صفحه اصلی Google Docs

    🔨 Practice

    🔨 تمرین

    Open your web browser. Type docs.google.com in the address bar. Press Enter.

    مرورگر خود را باز کنید. در نوار آدرس docs.google.com را تایپ کنید. Enter را بزنید.

  2. 2

    Create a new document

    یک سند جدید ایجاد کنید

    🖼️

    Screenshot: Blank document button (+)

    تصویر: دکمه سند خالی (+)

    🔨 Practice

    🔨 تمرین

    Click the + Blank button. A new empty document opens.

    روی دکمه + خالی (Blank) کلیک کنید. یک سند خالی جدید باز می‌شود.

  3. 3

    Type text

    متن تایپ کنید

    🖼️

    Screenshot: Cursor in a blank document

    تصویر: نشانگر ماوس در یک سند خالی

    🔨 Practice

    🔨 تمرین

    Click on the white page. Start typing some text with your keyboard.

    روی صفحه سفید کلیک کنید. با صفحه‌کلید خود شروع به تایپ متن کنید.

  4. 4

    Select text

    متن را انتخاب کنید

    🖼️

    Screenshot: Selected text highlighted in blue

    تصویر: متن انتخاب شده با رنگ آبی

    🔨 Practice

    🔨 تمرین

    Click and hold at the start of your text. Drag your mouse to the end. The text turns blue.

    در ابتدای متن کلیک کنید و نگه دارید. ماوس را تا انتهای متن بکشید. متن آبی می‌شود.

  5. 5

    Make text bold

    متن را پررنگ (Bold) کنید

    🖼️

    Screenshot: Bold button (B) in the toolbar

    تصویر: دکمه پررنگ (B) در نوار ابزار

    🔨 Practice

    🔨 تمرین

    Select some text. Click the B button in the toolbar. The text becomes bold (thicker).

    متنی را انتخاب کنید. روی دکمه B در نوار ابزار کلیک کنید. متن پررنگ (ضخیم‌تر) می‌شود.

  6. 6

    Save automatically

    ذخیره خودکار

    🖼️

    Screenshot: "Saved to Drive" message at the top

    تصویر: پیام "ذخیره شد در Drive" در بالای صفحه

    🔨 Practice

    🔨 تمرین

    Look at the top of the page. You will see "Saved to Drive". Google Docs saves your work automatically. You do not need to click Save!

    به بالای صفحه نگاه کنید. پیام "ذخیره شد در Drive" را می‌بینید. Google Docs کار شما را به طور خودکار ذخیره می‌کند. نیازی به کلیک روی Save نیست!

  7. 7

    Rename the document

    نام سند را تغییر دهید

    🖼️

    Screenshot: Document title field at top left

    تصویر: قسمت عنوان سند در بالا سمت چپ

    🔨 Practice

    🔨 تمرین

    Click on "Untitled document" at the top left. Type a new name. Press Enter.

    روی "سند بدون نام" در بالا سمت چپ کلیک کنید. یک نام جدید تایپ کنید. Enter را بزنید.

  8. 8

    Download as a Word document

    دانلود به عنوان سند Word

    🖼️

    Screenshot: File menu → Download → Microsoft Word

    تصویر: منوی File → Download → Microsoft Word

    🔨 Practice

    🔨 تمرین

    Click File (top menu). Click Download. Click Microsoft Word (.docx). The file saves to your computer.

    روی File (منوی بالا) کلیک کنید. روی Download کلیک کنید. روی Microsoft Word (.docx) کلیک کنید. فایل در کامپیوتر شما ذخیره می‌شود.

  9. 9

    Print the document

    سند را چاپ کنید

    🖼️

    Screenshot: Print dialog (Ctrl+P)

    تصویر: پنجره چاپ (Ctrl+P)

    🔨 Practice

    🔨 تمرین

    Click File → Print. Or press Ctrl + P on your keyboard. Choose your printer. Click Print.

    روی File → Print کلیک کنید. یا دکمه‌های Ctrl + P را روی صفحه‌کلید فشار دهید. پرینتر خود را انتخاب کنید. روی Print کلیک کنید.
