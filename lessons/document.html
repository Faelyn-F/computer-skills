The image above shows a document editor with 9 labelled controls. Each control is described in the cards below.

✨ New document سند جدید Start a fresh blank document. یک سند خالی جدید شروع کنید.
✏️ Document name نام سند Click the title to rename your document. روی عنوان کلیک کنید تا نام سند را تغییر دهید.
📝 Document page صفحه سند The main area where you type and edit text. قسمت اصلی که در آن متن تایپ و ویرایش می‌کنید.
🔤 Font فونت Choose the text style (for example, Arial or Times New Roman). سبک متن را انتخاب کنید (مثلاً Arial یا Times New Roman).
🔎 Font size اندازه فونت Make text larger or smaller. متن را بزرگ‌تر یا کوچک‌تر کنید.
📂 File menu منوی File Open the File menu to download, print or share. منوی File را برای دانلود، چاپ یا اشتراک‌گذاری باز کنید.
➕ Insert menu منوی Insert Add images, tables, page numbers and more. تصاویر، جدول، شماره صفحه و موارد دیگر اضافه کنید.
💾 Save status وضعیت ذخیره Your work saves automatically. Look for the saved message. کار شما به طور خودکار ذخیره می‌شود. پیام ذخیره شدن را ببینید.
📥 Download as PDF دانلود به صورت PDF Save a copy of your document as a PDF file. یک نسخه از سند خود را به صورت فایل PDF ذخیره کنید.
